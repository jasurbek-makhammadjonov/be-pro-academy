# 🤖 AI/ML Fundamentals Course

Notes and materials from the **AI/ML Fundamentals** course at **BePro Academy** (Tashkent, Uzbekistan).

## 📖 About the Course
A beginner-friendly, hands-on course that takes you from "what is data?" to building, evaluating and presenting your own machine learning project.

## 🧩 Modules
| # | Module | What you learn |
|---|--------|----------------|
| 1 | 🔍 Understand Data and AI | What data is, targets and features, data quality basics |
| 2 | 📊 Python, pandas, Matplotlib | Exploring and visualizing data |
| 3 | 🧹 SQL, Cleaning, Features | Data cleaning, feature creation, train/validation/test split |
| 4 | 📈 Regression and Classification | Baselines, models and evaluation metrics |
| 5 | 🧪 Scaling, Clustering, PCA | Scaling, K-means, PCA, anomalies, choosing a project |
| 6 | 🔁 Reproducibility | README, pipelines, JSON, Git, saving models with joblib |
| 7 | 🌐 Demo and Portfolio | Demo, portfolio page (HTML/CSS), writing a truthful CV |
| 8 | 🏆 Own Project | Building and presenting a personal project (30 Dec – 13 Jan) |

- 🌿 **Git** and **GitHub**

## 🎯 After the Course
By the end you will be able to:
- ✅ Explore a new dataset and check its quality
- ✅ Clean data, encode categories and scale numbers
- ✅ Split data correctly and build baseline regression and classification models
- ✅ Evaluate models with the right metrics
- ✅ Make a project reproducible with Git, a README and saved models
- ✅ Present your work in a demo, a portfolio page and a truthful CV

📌 **Level:** confident **beginner / junior-level** in applied machine learning. You can complete a small end-to-end ML project on your own. It is a strong foundation for internships and for deeper study in data science, ML or data engineering.
